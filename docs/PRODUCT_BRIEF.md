# Product Brief

Last verified: 2026-07-27

## Positioning

AstraBridge is for developers who want a local coding-agent workspace with a
Codex-derived core integration and explicit external-provider boundaries. Its
differentiator is evidence-qualified provider adaptation plus high-freedom
agent orchestration: developers can inspect task continuity, model metadata,
capability warnings, permissions, artifacts, recovery, and graph contracts
instead of treating every compatible endpoint as the same agent.

The public claim boundary is maintained in
[OPEN_SOURCE_PRODUCT_POSITIONING_AND_CLAIM_MATRIX.md](OPEN_SOURCE_PRODUCT_POSITIONING_AND_CLAIM_MATRIX.md).

## Primary Developer Outcomes

- Work in one visible `Project -> Task` workspace while provider/model/runtime
  changes remain internal execution-lane activity.
- Use local project state, checkpoints, file review, browser smoke, and
  secret-safe tool evidence.
- Evaluate external models as declared metadata, deterministic adapter evidence,
  reduced-authority routes, or exact-route verification instead of a single
  optimistic “supported” label.
- Author bounded orchestration graphs through inspectable GUI and code-facing
  representations; current public claims remain limited to the tested subset.

## In Scope

- API-key provider setup and health checks with redacted credential status.
- Local project management, checkpoints, file review, browser smoke, and tool
  evidence.
- A deterministic no-key first-ten-minutes fixture route that creates a local
  project, task graph, permission-visible state, and inspectable artifacts.
- Model metadata for reasoning, tools, modalities, MCP/external tools,
  plan/goal/compact behavior, and route authority.
- Deterministic graph import/export, dry-run, fixture, and recovery evidence
  within documented supported subsets.

## Explicit Non-Goals For v1

- Official OpenAI account login or official Codex configuration as a product
  path.
- A claim that an OpenAI-compatible response proves native coding-agent,
  reasoning, tool, streaming, or cancellation semantics.
- Universal autonomous external-provider routing or hidden tool authority.
- A plugin marketplace, cloud team governance, or silent writes to official
  Codex configuration.
- A public release before license, security-reporting, and reproducible
  onboarding gates are complete.
