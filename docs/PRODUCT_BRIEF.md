## In Scope

- Multi-provider coding tasks in one visible task thread.
- API-key provider setup and health checks.
- Local project management, checkpoints, file review, browser smoke, and tool evidence.
- Model metadata for reasoning, tools, modalities, MCP/external tools, plan/goal/compact behavior.

## Out Of Scope For v1

- Official OpenAI account login.
- Cloud team governance.
- Plugin marketplace.
- Silent writes to official Codex configuration.
